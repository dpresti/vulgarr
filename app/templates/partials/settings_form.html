Scene Detection

Detects candidate explicit-content scenes via a local frame classifier -- every candidate requires manual review before anything happens to a file (no auto-approve). Off by default: real CPU cost per scan, and produces a full second encoded "Vulgarr Edit" copy of the movie/episode once you apply approved scenes.

Minimum per-frame classifier score (0-1) to count as a hit. Kept permissive by default -- every candidate is reviewed manually either way, so a stricter value only risks missing real scenes.
